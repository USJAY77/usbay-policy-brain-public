REQUIRED VISUAL RESULT:
1. Locate the globe/icon used in the “USBAY Game” card.
2. Make the globe rotate continuously and slowly, as if it is alive.
3. Use a smooth, professional animation:
   - approximately 10–18 seconds per full rotation;
   - linear, infinite rotation;
   - no jerky movement;
   - rotate around the exact visual center.
4. Add subtle life without visual noise:
   - very soft glow or breathing pulse;
   - optional faint orbit/ring effect;
   - preserve the current cyan/blue/yellow USBAY appearance;
   - do not make it look childish, cartoonish, or like a loading spinner.
5. Keep the globe contained inside its current icon area:
   - no overlap with title, text, PLAY badge, or card border;
   - no layout shift;
   - no change to card dimensions.
6. On hover or keyboard focus:
   - rotation may become slightly faster;
   - glow may increase slightly;
   - the effect must remain subtle.
7. Respect accessibility:
   - add a `prefers-reduced-motion: reduce` fallback;
   - reduced-motion users must receive a static globe or extremely subtle non-rotating glow;
   - decorative animation must not be announced unnecessarily by screen readers;
   - preserve existing focus behavior and contrast.
8. Respect performance:
   - prefer CSS transforms and opacity;
   - use `transform: rotate(...)`;
   - avoid JavaScript animation loops unless absolutely required;
   - do not add large image/video assets;
   - do not introduce new dependencies unless unavoidable and approved.
9. Preserve responsive behavior on desktop, tablet, and mobile.
10. The animation must stop consuming work when the element is not visible where practical; do not introduce complicated observer logic unless already used in the project.
